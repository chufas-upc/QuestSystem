# Como probar
Dentro de Content esta la carpeta BPSystem, representando la implementación del sismtema utilizanddo Blueprints y CPPSystem utilizando el sistema en C++
Cada sistema tiene su mapa L_Quest_Blueprints y L_Quest_CPP

Al **Interactuar** con los *QuestGiver*, le dan una mision al jugador
Al hacer **Overlap** con los *CoinCollector*, se activa la actualización de los objetivos al GameState
